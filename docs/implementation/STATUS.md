## 已选定的设计方向

1. 英文合成会议 + 内外部两个视图；外部只承诺已声明的邮箱检测基线和已知字段投影。
2. 固定 OPA 模板读取严格契约，不上传任意规则语言。
3. 数据返回前提交 PostgreSQL receipt/outbox；Redis 不作为唯一审计事实来源。
4. 尽早验证官方 A2A 接口，随后复用一个交付核心。
5. 版本固定不会阻止当前权限撤销生效。
6. 当前视图/会议资源 grant 独立于契约版本；最终授权检查与 receipt 许可提交同一事务，定义明确的撤权顺序。
7. 请求/响应资源 ID 必须一致；兼容性分类分别约束草案、激活和默认版本切换。
